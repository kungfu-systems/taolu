# Security policy

Report vulnerabilities privately through GitHub Security Advisories for `kungfu-systems/taolu`. Do not open a public issue containing exploit details, credentials, private URLs, or unreleased artifact information.

Security fixes are supported for the latest stable Taolu release. Installer security properties include SHA-256 verification before extraction, HTTPS-only network downloads, safe archive paths, link rejection, bounded ownership, staged activation, and explicit rollback state. A Site must obtain catalog digests from a trusted product release authority; Taolu does not treat asset names or transport success as authenticity.
